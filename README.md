# Companhia das Máscaras Gregas

Site do trabalho de Artes e História da Cultura Ocidental (2º Ano A · Divinópolis, MG, 2026)
sobre as máscaras do teatro grego, com abas de tema, mídia, artigo, slides e um
agente de IA que responde perguntas sobre o assunto.

Página única e autocontida: todo o HTML, CSS e JS estão em [`index.html`](./index.html).

## Como visualizar

Abra `index.html` no navegador, ou:

```bash
python3 -m http.server 8000   # http://localhost:8000
```

As anotações originais do curso de Copilot Studio estão em [`Trabalho.md`](./Trabalho.md).
